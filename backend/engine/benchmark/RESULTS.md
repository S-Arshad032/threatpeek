# Benchmark results

Generated by `npm run benchmark -- --set=<dev|heldout|heldout2|heldout3>` in `backend/engine`. These are
small, synthetic, English-only test sets; the numbers are not a guarantee of real-world accuracy.
dev, heldout and heldout2 were written by the same author with fictional brands and reserved
domains. The dev set was used to tune the rules; the held-out sets were not.

heldout3 (30 messages, 15 scam / 15 benign) was written by a third party (Gemini) and was not seen
while the rules were written. It uses real Bangladeshi service names (bKash, Nagad, DESCO...) and
throwaway defanged domains. Known limitation: the original draft had 3 romanized-Bengali messages,
which were replaced by English versions because the engine is English-only, so the set does not
measure mixed-language messages. h3-s06 (scam: "my main number got blocked... urgent 3,000 BDT
bKash") and h3-b13 (benign: "my card got declined... send me 600 BDT on bKash") are near-twins
that a rule engine cannot reliably separate; they scored 15 and 0.
